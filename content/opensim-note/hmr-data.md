# 数据筛选与视频切分

## 已筛选 3 个高质量单人合集

- **Kyra Pro**：588 条视频；舞蹈有氧、步行、拳击/踢拳、HIIT、家庭力量、芭蕾、瑜伽/拉伸。
- **MadFit**：780 条视频；全身/核心、上下肢力量、哑铃、低冲击、舞蹈/芭蕾、热身冷身、瑜伽拉伸。
- **Pamela Reif**：260 条视频；核心腹部、臀腿、上肢、HIIT/Cardio、舞蹈、普拉提/瑜伽、拉伸、器械。

## 处理主线

1. **视频筛选**：单人主体、动作清晰、机位稳定。
2. **倒计时 OCR**：识别倒计时变化，获得候选时间点。
3. **边界校正**：去重、容错与连续区间合并。
4. **视频切分**：先切片，统一视频片段粒度。
5. **HMR 提取**：逐片段恢复人体运动序列。

当前处理规模约 **350 h**。倒计时作为弱监督边界，能够减少冗余计算，提升视频片段粒度一致性。
