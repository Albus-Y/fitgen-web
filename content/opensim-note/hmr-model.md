# HMR 管线优化与 GVHMR 选型

## PromptHMR 优化：用磁盘换取内存空间

将解码帧从内存驻留改为磁盘帧缓存，以降低单 worker 的 RAM 峰值，提高可用 worker 数量与整体吞吐。长片段和高并发场景下仍需控制资源峰值。

这是当前可复现的基线方案。

## 最终选择：GVHMR

GVHMR 更适合连续、单人、固定机位的健身视频：

- **时序连续**：跨帧动作更连贯，减少逐帧抖动。
- **全局稳定**：人体姿态与全局轨迹更一致。
- **场景匹配**：契合单人、固定机位和连续动作片段。
- **便于下游**：输出易于标准化为统一动作序列。

选型结论：在精度、时序一致性、资源消耗与批处理稳定性之间更均衡。
