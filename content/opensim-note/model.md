# OpenSim 如何表示人体骨骼与肌肉

## 1. 骨骼与关节
OpenSim 把人体表示为由关节连接的刚体链，例如骨盆、大腿骨、小腿骨和脚。
每个刚体包含质量、惯性以及空间位置和旋转等信息。关节定义刚体之间如何运动，以及允许运动的自由度；例如，简化的膝关节可以只保留屈伸这一个角度自由度。
```
骨盆 → 大腿骨 → 小腿骨 → 脚
       关节连接各个刚体
```
## 2. 肌肉与 MTU 的结构
MTU（Muscle-Tendon Unit，肌肉—肌腱单元）由肌纤维和肌腱构成。理解它时，可以分成几何和动力学两个层面。
### 几何层：路径决定长度和力臂
肌肉在模型中沿一系列路径点连接骨骼，包括起点、终点、中间点，以及绕过 wrapping surface 时形成的包绕点。
这些路径点决定整个 MTU 的长度 $L_{MTU}$，以及肌肉对关节作用的力臂 $r$。骨骼运动时，肌肉路径和相应的几何量随之变化。
### 动力学层：肌纤维产力，肌腱传力
- 肌纤维（contractile element）：产生主动收缩力，受激活程度、肌纤维长度和收缩速度影响。
- 肌腱（tendon）：传递肌肉力，并通过伸长储存弹性能量。
沿用原文忽略羽状角的简化表示，长度关系为：
$$
L_{MTU} = L_f + L_t
$$
肌纤维力经肌腱传递到骨骼，再通过力臂产生关节力矩：
$$
\tau = rF
$$

## 3. 肌肉的受力计算
原文用 Hill-type muscle model 的简化形式描述肌肉力：
$$
F_{muscle} = F_{max} \times f_a(a) \times f_l(L_f) \times f_v(v_f)
$$
|量|含义|在计算中的作用|
|---|---|---|
|$F_{max}$|最大等长肌肉力|给出肌肉力的尺度|
|$a$ 与 $f_a(a)$|激活程度及其作用|决定肌肉被激活的程度|
|$L_f$ 与 $f_l(L_f)$|肌纤维长度及力—长度关系|描述长度对产力能力的影响|
|$v_f$ 与 $f_v(v_f)$|肌纤维收缩速度及力—速度关系|描述收缩速度对产力能力的影响|
输出为每条肌肉的力，单位为 N；通过力臂可以进一步计算它对关节的力矩。
## 4. 代谢模型接收哪些量
在得到肌肉状态后，将以下量传入代谢模型（如 Umberger）：
|输入量|含义|
|---|---|
|activation|肌肉激活程度|
|fiber length|肌纤维长度|
|fiber velocity|肌纤维收缩速度|
|force|肌肉力|
这些是随动作变化的输入，计算还使用模型中预设的肌肉参数。代谢模型输出代谢功率（metabolic rate），再对时间积分并换算为 kcal，得到这段动作的代谢能耗。
