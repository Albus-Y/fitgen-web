# Pamela 原子动作八拍编排

模块 4 的第三个 Demo 位于 `dist/pamela-dtw-demo/index.html`。三栏共享原音乐、原子动作和音乐时钟，分别播放原速循环、服务器 Anchor xTW 与 GPT-6.2 Astra 独立编排。“容许倍率”可切换 0.8–1.5×（默认）和 0.8–1.2×。同一动作切档时保留音乐位置、循环区间及播放状态，切换动作时沿用当前倍率档。打开页面时原音乐默认开启，播放器暂停在参考窗口的第一拍，循环与拍点提示音默认关闭。主页模块 4 的「Demo 3 · 原子动作八拍编排」标签直达慢速深蹲的 0.8–1.2× 双八拍回放。

## 素材和时间轴

原子动作取自用户指定的 MotionDatasetTest。清单保存实际 GLB 的 SHA256、atom ID、原片起止帧和轮内拍点。通过原片帧区间复用已审查的动作 beat。每个原子动作有 22 个身体关节、20 FPS 内容帧和一个末端边界姿态。

| 动作 | 原片半开帧区间 | 周期 | 内容帧 | 轮内事件（秒） | 参考音乐区间（秒） |
|---|---|---:|---:|---|---|
| 慢速深蹲 | [481, 538) | 2.85 s | 57 | 1.35、2.75 | 0.87–4.71 |
| 开合跳 | [481, 516) | 1.75 s | 35 | 0.20、1.15 | 1.59–5.43 |
| 俯身触地跳 | [49, 79) | 1.50 s | 30 | 0.65、1.40 | 2.31–6.15 |

三栏使用相同的周期采样器。骨盆的水平净位移逐轮累计，渲染相机跟随水平根位移。一个周期包含恰好 $P f_m$ 个内容帧，最后一个帧间隔插值到下一轮的第 0 帧，GLB 的边界关键帧用于确定周期和水平位移。整段输出取音乐绝对时刻 $t=k/20$，共 600 帧；页面播放与导出使用同一映射，允许按屏幕刷新率在帧间查看。

## 参考组求解

八拍取真实的九个时间边界，第 1 拍至下一组起点共八个拍间隔。三段参考组长度均为 3.84 秒，右边界均为已确认音乐拍。这个拍可以作匹配和误差参照，音轨按照原始全片索引只在该时刻发声一次。

原子周期为 $P$，八拍长度为 $T$，所选上限为 $v_{\max}$，候选轮数满足

$$
\left\lceil\frac{0.8T}{P}\right\rceil\le n\le\left\lfloor\frac{v_{\max}T}{P}\right\rfloor.
$$

服务器用 `xtw.retime_motion_to_music` 在 $[0,T]\to[0,nP]$ 上求解。宽档有四个候选，窄档有两个。描述子、Drop-DTW、GDTW 均使用服务器实现，各档单独设置局部速度上下限，其余使用模块默认配置。两档清单分别为 `eight-count/manifest.json` 和 `eight-count/manifest-1.2.json`，共用相同指纹的三份原子骨架。

独立子代理以 `gpt-6.2-astra` 显式启动，使用独立上下文。输入包括原子周期、已确认动作转折、音乐拍、时长和倍率界。它编写的 `arrange_atom_astra.py` 在源动作帧处表示逆速度 $u=dt/ds$，令 $1/v_{\max}\le u\le1.25$，组首与组末速度相等且自由取值。对速度积分得到转折时刻，使用 SciPy/HiGHS 最大化有序一对一命中，最小化全部转折平均误差，在距最佳均值 10 ms 的窗口内依次减小速度波动及原速偏差。结果保留逆速度节点与可复现的离散映射。

两种方法独立选轮数。先比较全部 $2n$ 个转折在 ±100 ms 内的命中比例。同率时保留距最低平均绝对误差 10 ms 以内的候选，依次取倍率相对 1× 的时间加权均方根偏差、倍率总变化量、轮数最小的方案。

### 慢速深蹲的双八拍窗口

在「编排窗口」中选择「2 个八拍」，或[直接打开窄档双八拍](../dist/pamela-dtw-demo/index.html?window=2&rate=1.2)。两个八拍共享中点，在 17 个真实时间边界上连续运行服务器 Anchor xTW。参考窗口为 0.87–8.55 秒，三次深蹲平均需要 1.113×，四次需要 1.484×。

| 容许倍率 | 轮数 | 映射转折命中（±100 ms） | 平均误差 | 实际倍率 | 选用 |
|---|---:|---:|---:|---:|---|
| 0.8–1.2× | 3 | 4/6 | 101.6 ms | 1.045–1.176× | 是 |
| 0.8–1.5× | 3 | 4/6 | 99.3 ms | 1.048–1.223× | |
| 0.8–1.5× | 4 | 8/8 | 31.8 ms | 1.438–1.500× | 是 |

第 3–4 组和第 5–6 组沿用参考组的轮数、转折拍位和完整映射，在各自的 17 个真实边界之间逐拍迁移。局部超限时固定端点，用与单八拍相同的有界最小二乘修正速度。第 5–6 组的最大源时间修正为窄档 0.12 ms、宽档 47.19 ms。第 7 组（23.90–27.74 秒）单独收尾。宽档可独立完成两轮，窄档播放双八拍模板的前八拍，随后按接续的动作相位进入段尾。界面分别显示映射转折和重采样骨架的检测成绩。

在已有 Module2_xtw 环境中，用以下命令生成网页数据与逐帧参照。将输出的 `slow_squat-16.json` 放入网页的 `eight-count/`，完整骨架留在实验目录。

```text
python -B scripts/build_squat_two_eights.py --module-root <Module2_xtw> --manifest <eight-count/manifest.json> --music <pamela-beat-demo/analysis.json> --atom <eight-count/slow_squat.f32> --output <新结果目录>

```

## 迁移与实际骨架

每个后续完整组按九个真实音乐边界搬移参考映射的全部折点。若某个间隔越过速度界，用带上下界和固定总位移的最小二乘，仅调整这一组的速度。其目标为 $\sum_i\Delta t_i(v_i-r_i)^2$，其中 $r_i$ 为直接迁移的速度，$v_i$ 为最终速度。清单逐组保存修正量。整段共有 7、7、6 个完整组。段首残拍取模板尾部，段尾或中间残拍取其前部，无拍区使用原速。残段或空缺之后的完整组回到第 0 帧；俯身触地跳的两次中途重置位于 8.07 和 25.35 秒。

时间轴分别显示映射转折和从最终 20 FPS 骨架重新提取的转折。重检测沿用关节平均位移、5 帧高斯平滑、reflect 边界和 0.2 秒最小间隔。例如俯身触地跳的 Astra 参考组有 6/6 个映射转折命中；实际重检测到 3 个转折，其中 2 个命中。可在画面检查这些差异与循环接缝。

## 复现

在 FitGen 仓库执行。输入、服务器结果、完整验证骨架放入新的实验目录，网页仅发布三份小型骨架和候选/迁移映射。

```text
python -B scripts/build_pamela_eight_count.py prepare --atom-root <MotionDatasetTest> --work <新实验目录> --max-rate <1.5 或 1.2>
```

在已有 Module2_xtw 环境中，将输入清单和 `scripts/run_atom_anchor.py` 放入单独实验目录，按深蹲、开合跳、俯身触地跳顺序指定三个与输入指纹一致的 GLB。适配器目录包含原审查使用的 `glb_to_module2_skel.py`。

```text
python -B run_atom_anchor.py --inputs inputs.json --output server --module-root <Module2_xtw> --adapter-dir <GLB适配器目录> --atoms <深蹲GLB> <开合跳GLB> <俯身触地跳GLB>
```

每档使用独立实验目录。把各自的 `server/` 放回对应目录，分别 assemble。更新网页时将两份清单、六份编排 JSON 与三份共享 f32 同步到 `dist/pamela-dtw-demo/eight-count/` 并刷新资源版本串。

```text
python -B scripts/build_pamela_eight_count.py assemble --work <实验目录> --output <新结果目录>
node scripts/test_pamela_eight_count.mjs <宽档实验目录> <窄档实验目录>
node scripts/test_pamela_dtw.mjs
python -X utf8 scripts/build.py
python -X utf8 scripts/check.py
```
